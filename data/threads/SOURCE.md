# Thread colour data

`dmc-floss.csv`: DMC six-strand embroidery floss (Mouliné Spécial, art. 117), 489 colours.

- Source: [craft-color-codes](https://github.com/makebead/craft-color-codes) by
  [MakeBead](https://makebead.com/), file `data/csv/dmc-floss.csv`, commit `84dbdc2`
  (downloaded 2026-10-27), unchanged.
- License: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Credit required:
  "Color data: craft-color-codes by MakeBead (https://makebead.com)". The app shows it under
  the colour list.
- Colour codes and product names belong to DMC. RGB values are approximations of real thread.

`dmc-floss.csv.import` sets the importer to "keep" so Godot ships the file as is instead of
importing it as a translation table.
